# Plan

Resolve the remaining F8–F14 review findings as a behavior-preserving cleanup focused on clear ownership, fewer internal surfaces, stronger lifecycle safety, and a shallower project structure. The work will keep the exact public SDK API, existing media behavior, macOS target support, and current test baseline while avoiding new runtime dependencies or speculative abstractions.

## Scope

- In: FFmpeg session cleanup and error ownership; audio and streaming-controller lifecycle coverage; internal media terminology; removal of redundant wrappers, exports, and unsupported branches; build-script deduplication; enforceable module boundaries; test-support and app-layout cleanup; WebView listener cleanup; small CSS/import housekeeping; documentation and full verification.
- Out: Public API changes; new product features or media formats; Linux or Windows support; replacement of FFmpeg or the existing assets; broad Rust/Tauri redesign; splitting cohesive CRT or sidecar lifecycle modules; collapsing the media layer into fewer, mixed-responsibility files; generic `utils/` folders; new runtime dependencies.
